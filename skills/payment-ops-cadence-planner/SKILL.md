# Payment Ops Cadence Planner

## Purpose

Generate an operating calendar for payment teams across daily checks, WBRs, MBRs,
QBRs, annual planning, and three-year strategy.

## When To Use

Use when the user asks:

- `What should my payments operating cadence be?`
- `Build a review calendar for the payments team.`
- `What should we inspect daily vs weekly vs quarterly?`

## Inputs

- business type: subscription, marketplace, ecommerce, platform, usage-based SaaS
- payment volume and regions
- processors and payment methods
- known failure modes
- stakeholder groups
- fiscal-year timing

## Process

1. Map each cadence to its business objective.
2. Assign metrics, audience, artifact, and owner.
3. Add timing recommendations.
4. Separate operating checks from executive communication.

## Output

Return a calendar with:

- cadence
- meeting or review name
- timing
- audience
- inputs
- output artifact
- owner
- decision or action expected
